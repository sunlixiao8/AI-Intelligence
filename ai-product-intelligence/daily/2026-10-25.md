## 1. AI Clothes Changer（FitIn）

**链接：** https://trustmrr.com/startup/ai-clothes-changer  
**类别：** AI 图像生成 / 服装试衣 / 电商视觉  
**目标用户（推测）：** 想在线试穿搭的消费者、独立服装卖家、内容创作者、小型电商运营。  
**证据等级：** 产品功能由名称和类别推断；收入来自 TrustMRR 摘要，功能与定价需进一步验证。

### 1.1 用户问题

线上买衣服最大的痛点是“看不清上身效果”。消费者担心尺码、版型、颜色；小卖家则要承担模特拍摄、场景图、上新图的成本。  
如果 AI 能把“人物照片 + 服装图片”快速合成试衣图，用户付费理由通常不是好奇，而是：

- 卖家：减少拍摄成本、加快上新、提升转化率；
- 创作者：批量产出穿搭内容；
- 消费者：降低退货不确定性。

但要注意：**“试衣”与“换装图”是两件事。** 真正准确的尺码试衣很难；电商模特图、场景图、平铺图转模特图更容易商业化。

| 售价/倍数 | $4,800；1.8x |
| 推测月收入 | `$150-$300/月` |
| 置信度 | 低-中：仅单一市场页面摘要，未见定价页、用户数和支付流水 |

### 1.3 为什么可能赚钱

- **使用频率：** C 端中低；卖家上新季中高。
- **紧迫程度：** 卖家在换季、上新、广告投放前有明确时间压力。
- **预算负责人：** 小卖家老板、电商运营、内容创作者本人。
- **切换成本：** 低。工具之间容易替换，所以必须靠工作流、模板、批量能力和出图稳定性留人。
- **商业判断：** 这不是“技术炫技型”产品，而是“省拍摄成本型”产品。个人创业者应优先卖给卖家，而不是先做 C 端试衣。

### 1.4 产品逻辑与技术路径

**适合初学者的 MVP：**

> 上传一张服装平铺图/商品图 → 选择模特模板和场景 → 生成 5-10 张电商展示图 → 下载或批量导出。

不要第一版就承诺“准确尺码试衣”。先做“服装图变模特图/场景图”，更容易交付，也更容易收费。

**核心工作流：**

1. 用户上传人物图或选择模特模板；
2. 上传服装图；
3. 系统做背景移除、服装区域识别；
4. 调用图像生成/编辑模型合成；
5. 输出多姿势、多场景图；
6. 用户挑选、重生成、下载。

**需要的数据：** 人物照片、服装图、场景模板、用户授权同意、生成记录。  
**推荐技术栈：** Next.js + Tailwind + Supabase（认证/存储/数据库）+ Stripe/Lemon Squeezy + 图像生成 API + 队列任务 + PostHog。  
**AI 用法：** 视觉生成、图像分割、背景移除、提示词模板、批量任务编排。

**如果我来开发，最大问题：**

1. **一致性和真实感**：脸、手、衣服褶皱、图案、颜色容易崩；一旦不像，用户不会付费。
2. **成本与延迟**：图像生成按张计费，重试次数多会吃掉毛利；批量任务需要队列。
3. **隐私与滥用**：人物照片涉及肖像权、未成年人、NSFW 风险，必须有授权、审核和删除机制。
4. **期望管理**：用户以为能“准确试尺码”，但实际只能做视觉展示，容易退款和差评。

**降低难度的捷径：**

- 先做 B 端“平铺图→模特图”，不做真实试衣；
- 限定姿势、场景、服装类型；
- 人工审核 + 自动生成混合；
- 按积分收费，重生成消耗积分；
- 只支持 2-3 个模板，先把出图稳定性做好。

### 1.5 适合 OPC 初学者的机会

**更小众版本：** 面向 Shopify/Etsy/独立站服装卖家的“上新图工厂”，按张收费。  
**第一批访谈对象：** 独立服装店主、淘宝/小红书服装商家、模特经纪、电商代运营。  
**1 周验证实验：**

- 做 1 页落地页，写清“上传平铺图，24 小时交付 10 张模特图”；
- 手动用现成图像模型跑 10 个案例；
- 找 5 个卖家，先卖 20 张图 $19-$49；
- 只验证“是否愿意为省拍摄时间付费”，不急着开发完整产品。

## 2. Social Genius: Text Analyzer

**链接：** https://trustmrr.com/startup/social-genius-text-analyzer  
**类别：** AI 文本分析 / 社交媒体内容优化  
**目标用户（推测）：** 创作者、社交媒体运营、品牌营销团队、代运营机构。  
**证据等级：** 产品名称和类别较清楚；具体功能、定价、客户数未知。

### 2.1 用户问题

社交媒体运营每天面对大量文案、评论、脚本和竞品内容。真正难的不是“写出来”，而是判断：

- 这条内容为什么有效？
- 开头钩子够不够强？
- 语气是否符合受众？
- CTA 是否清楚？
- 评论区情绪是什么？
- 怎样改成更好的版本？

如果工具能把“文本分析 + 修改建议”做成固定工作流，用户付费理由是节省时间、提高内容表现、减少试错。

### 2.2 商业信号

| 项目 | 内容 |
|---|---|
| 官方收入 | 未找到公司官方披露 |
| 平台展示收入 | $976/月（TrustMRR 摘要，2026-10-25 访问；口径待核） |
| 售价/倍数 | $25,000；2.1x |
| 推测月收入 | `$700-$1,200/月` |
| 置信度 | 低-中：有收入与售价线索，但缺定价、用户数、评价 |
| 定价模式 | 未知；可能是订阅/积分/按报告收费 |
| 牵引力证据 | 已挂售；名称指向明确场景；缺少评论和流量数据 |

来源：https://trustmrr.com/startup/social-genius-text-analyzer  
市场页：https://trustmrr.com/

### 2.3 为什么可能赚钱

- **使用频率：** 社交媒体运营是高频工作，每周甚至每天使用。
- **紧迫程度：** 中高。内容发布有截止时间，分析报告和改写建议能直接进入工作流。
- **预算负责人：** 营销负责人、创作者本人、代运营老板。
- **切换成本：** 中低。若工具积累历史内容、品牌语气和最佳案例，切换成本会上升。
- **商业判断：** “通用文本分析”很容易同质化；真正值钱的是垂直场景的评分标准和历史数据。

### 2.4 产品逻辑与技术路径

**适合初学者的 MVP：**

> 粘贴一条帖子/脚本/评论 → 输出钩子评分、情绪、可读性、CTA 强度、受众匹配度 → 给出 3 个改写版本。

第一版不要做“全平台社交分析”，先做一个垂直场景，例如：

- LinkedIn B2B 创始人帖子；
- Etsy 商品标题和描述；
- YouTube Shorts 开头钩子；
- 小红书/公众号标题诊断。

**核心工作流：**

1. 用户粘贴文本或上传历史帖子；
2. 选择平台、目标受众、目标动作；
3. AI 按评分表分析；
4. 输出问题清单和改写建议；
5. 用户保存报告、对比历史版本。

**需要的数据：** 用户文本、平台规则、品牌语气、可选历史高表现帖子。  
**推荐技术栈：** Next.js + Supabase + OpenAI API + pgvector（存储风格样本）+ Stripe。  
**AI 用法：** 文本分类、抽取、评分、生成改写、embedding 检索相似案例。

**如果我来开发，最大问题：**

1. **建议太泛**：AI 很容易输出“增加互动、保持简洁”这种废话。必须用评分表、示例和平台规则约束。
2. **信任问题**：用户不相信一个通用模型懂他的受众。需要展示“为什么这样评分”，并允许人工调整。
3. **缺少专有数据**：没有历史高表现内容，就很难形成壁垒。
4. **隐私**：用户可能粘贴未发布内容、客户评论，需要明确数据保留策略。

**降低难度的捷径：**

- 只做一个平台、一种内容类型；
- 人工整理 50 条优秀/糟糕样例，做评分基准；
- 先卖“人工 + AI 的内容诊断报告”，再产品化；
- 用固定模板输出，不让模型自由发挥。

### 2.5 适合 OPC 初学者的机会

**更小众版本：** “LinkedIn B2B 帖子体检器”或“Etsy 商品描述优化器”。  
**第一批访谈对象：** 社交媒体代运营、B2B 创始人、Etsy 卖家、内容创作者。  
**1 周验证实验：**

- 找 10 条用户已发布内容，用 GPT + 评分表生成诊断报告；
- 人工对比“高表现/低表现”帖子，验证评分是否有区分度；
- 向 5 个运营者收费 $9/份报告，观察是否愿意复购；
- 若复购成立，再做订阅版。

## 5. 今日模式

**模式：微型 AI 产品的估值，越来越像“收入质量”而不是“功能炫酷”。**

今天三个案例给出三种信号：

- **AI Clothes Changer**：收入小，但场景具体，适合个人创业者做窄 version；
- **Social Genius**：收入中等，场景清楚，但必须靠垂直评分标准和历史数据建立差异；
- **Knightvision**：收入高，但信息不透明，低倍数提醒我们：买方不为“看不懂的收入”付高溢价。

对个人创业者的启示：

> 先卖一个能被量化省时、能人工兜底、能按次/按月收费的窄工作流；再逐步产品化。不要一开始做“大平台”或“通用 AI”。

## 6. 建造雷达

### 雷达 1：服装卖家“上新图工厂”

- **目标：** Shopify/Etsy/独立站服装卖家；
- **MVP：** 上传平铺图 → 生成 5 张模特图/场景图；
- **收费：** $19/20 张起，或 $29/月；
- **验证：** 先手动交付 10 单，看出图稳定性和复购。

### 雷达 2：垂直文案体检器

- **目标：** LinkedIn B2B 创始人、Etsy 卖家、YouTube Shorts 创作者；
- **MVP：** 粘贴文本 → 钩子/情绪/CTA/受众匹配评分 → 3 个改写版本；
- **收费：** $9/报告，或 $19/月；
- **验证：** 用 50 条高/低表现内容做评分基准，卖给 5 个运营者。

### 雷达 3：AI 产品毛利雷达

- **目标：** 有收入的 AI 独立开发者；
- **MVP：** 接入 API 账单 + 客户用量，算每个客户毛利、重试成本、流失风险；
- **收费：** $15/月；
- **验证：** 先帮 3 个创始人手工算毛利，问他们是否愿意自动化。

## 7. 用户访谈问题

直接问潜在用户：

1. **“你最近一次做［具体任务］是什么时候？花了多久、花了多少钱？最后怎么解决的？”**  
   目的：确认问题是否高频、是否已有付费替代方案。

2. **“如果有一个工具能在［具体时间］内产出［具体结果］，你最担心什么？什么情况下你会立刻付费？”**  
   目的：区分好奇试用和真实付费，找出信任障碍。

3. **“你现在为哪些相关工具、外包或广告付费？如果新工具只替代其中一小步，你愿意付多少/月？”**  
   目的：找到预算负责人和可接受价格带。
