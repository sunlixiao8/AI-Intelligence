## 1. WPConvert.ai：把 AI 生成的网站搬到 WordPress

**来源链接**：  
- TrustMRR 列表：https://trustmrr.com/  
- 产品页：https://trustmrr.com/startup/wpconvert-ai

### 1）产品
- **名称**：WPConvert.ai
- **类别**：AI 网站转换 / WordPress 迁移 SaaS
- **目标用户**：用 Framer、Webflow、Lovable、v0、Bolt 等 AI 或低代码工具生成网站后，需要迁移到 WordPress 的创业者、自由职业者、建站代理、企业市场团队。
- **事实**：TrustMRR 列表写 “WPConvert.ai - Convert AI sites to WordPress SaaS”。

### 2）用户问题
AI 建站工具出原型很快，但很多客户、SEO 团队、托管方仍然要求 WordPress。手动把 HTML/CSS/JS 转成 WordPress 主题、Gutenberg 区块或 Elementor 模板，非常耗时，而且容易漏掉响应式、表单、SEO 元数据、图片和动画。

用户付费不是因为好奇，而是因为：
- 代理公司可以把它包装成 $500-$2000 的迁移服务；
- 个人创业者愿意付 $49-$199 省 10-20 小时；
- 迁移卡在上线前，属于紧迫任务。

以上价格是推测，不是官方定价。

### 3）商业信号
- **定价模式**：未知。TrustMRR 摘要没有显示定价页。
- **月收入估算**：`$5.4k/月`
- **置信度**：中
- **证据**：TrustMRR 摘要显示 “FOR SALE WPConvert.ai - Convert AI sites to WordPress SaaS Revenue $5.4k Price $240k Multiple 3.7x”。按 $240k ÷ 3.7x 反推，年收入约 $64.9k，折合月收入约 $5.4k。链接：https://trustmrr.com/ 和 https://trustmrr.com/startup/wpconvert-ai
- **增长/牵引力**：以 $240k 出售，multiple 3.7x。用户评价、流量、定价未知。

### 4）为什么可能赚钱
- **使用频率**：项目制，但建站代理每月多个项目。
- **紧迫程度**：上线前必须迁移，卡发布。
- **预算负责人**：代理老板、创业者、企业市场负责人。
- **切换成本**：迁移后回退麻烦，但工具可替换。关键是转换质量和速度。

### 5）产品逻辑与技术路径
**适合初学者的 MVP**：  
不要做“支持所有 AI 建站工具”。先做一种输入：上传纯 HTML/CSS/JS zip 或一个 URL，输出基础 WordPress 主题 zip + 安装说明。

**核心工作流**：  
输入 URL/zip → Playwright 抓取 HTML/CSS/图片 → LLM 识别区块（导航、hero、定价、功能、评价、页脚）→ 映射到 Gutenberg 区块或 Elementor JSON → 生成 theme.json、style.css、functions.php → 打包下载。

**需要的数据/输入**：  
HTML、CSS、图片、字体、页面路由、SEO 元数据、表单、动画设置。

**推荐技术栈**：  
Next.js + Tailwind；Supabase 存任务和文件；Stripe/Lemon Squeezy 收款；OpenAI API 做区块分类和代码生成；JSZip 打包；Playwright 抓取；WordPress REST API 做可选自动安装。

**AI 用法**：  
分类、抽取、代码生成、视觉理解。

**如果我来开发，最大难点**：  
不同 AI 建站工具输出的 DOM/CSS 差异极大。绝对定位、响应式、动画、表单、SEO 元数据很难一一映射。WordPress 插件和主题兼容性坑多。最容易失败在“演示能转，真实站点转完不能维护”。

**捷径**：  
第一版只支持一种来源，比如 Framer 导出或纯 HTML；只输出 Gutenberg 主题，不做 Elementor；转换后人工审核；按次收费 $49-$199，先服务 10 个客户再自动化。

### 6）适合 OPC 初学者的机会
- **更小众版本**：只做 “Lovable → WordPress” 或 “Webflow → WordPress”；或只做律师、餐厅、房产行业模板转换。
- **第一批访谈客户**：建站代理、自由职业者、Reddit r/WordPress、r/webdev、Indie Hackers 里抱怨迁移的人。
- **1 周验证实验**：发帖提供“手动 + 半自动”迁移服务，收费 $99，目标拿到 10 个意向。如果 3 天内有人预付，再开发自动化。

### 4）为什么可能赚钱

- **紧迫程度**：中等，创作者有截止日期。
- **预算负责人**：创作者、营销团队、播客制作人。

### 5）产品逻辑与技术路径
**适合初学者的 MVP**：  
不做全品类音频平台。先做一个垂直工作流：输入脚本 → 选声音 → 生成旁白 → 自动加字幕 → 导出 MP3/SRT。

文本输入 → 分段 → TTS/音乐生成 → 音量标准化 → 字幕对齐 → 下载。

**AI 用法**：  
文本转语音、音乐生成、语音克隆、字幕对齐。

**如果我来开发，最大难点**：  
音频质量和延迟；GPU/API 成本会吃掉毛利；声音克隆和音乐版权有合规风险；用户对“听起来像人”要求高。

**捷径**：  
先用第三方 API 封装“短视频旁白 + 字幕”单一场景，不做音乐生成；用预置声音，不做克隆；按秒或按月收费，控制成本。

### 6）适合 OPC 初学者的机会
- **更小众版本**：短视频自动旁白 + 字幕 + 一键发布；播客片头/片尾生成；课程音频本地化。
- **第一批访谈客户**：短视频创作者、播客主、在线课程老师。
- **1 周验证实验**：用 ElevenLabs 或类似 API 做 10 个 60 秒短视频旁白样品，向 20 个创作者报价 $19/月，观察是否有人愿意预付。

**证据不足说明**：TrustMRR 摘要没有给出 Sonora AI 的官网、定价、产品描述。下一步必须访问产品官网、查看定价页、搜索创始人访谈，否则不要把上述假设当成事实。

付费意愿：个人开发者对低价工具愿意试，但收入仅 $73/月，说明需求可能不够强，或产品太早。

### 3）商业信号
- **定价模式**：未知。
- **月收入估算**：`$73/月`
- **置信度**：中
- **证据**：TrustMRR 摘要显示 “Termi Protocol:AI Vibe Coding Artificial Intelligence Revenue $73 Price $4k Multiple 4.6x”。按 $4k ÷ 4.6x 反推，年收入约 $870，折合月收入约 $73。链接：https://trustmrr.com/ 和 https://trustmrr.com/startup/termi-protocol
- **增长/牵引力**：以 $4k 出售，multiple 4.6x。收入极低，增长证据弱。

### 4）为什么可能赚钱
- **使用频率**：开发者每天用终端。
- **紧迫程度**：遇到报错时高。
- **预算负责人**：个人开发者，预算低。
- **切换成本**：如果集成到现有终端/CLI，中等；但替代品多。

### 5）产品逻辑与技术路径
**适合初学者的 MVP**：  
做一个 CLI 或 VS Code 插件，只做“错误解释 + 建议命令”，不自动执行。

**核心工作流**：  
捕获终端输出 → LLM 解释错误 → 给出修复命令 → 用户确认后复制/执行 → 记录常见问题。

**需要的数据**：  
终端日志、项目文件、依赖版本、错误堆栈。

**推荐技术栈**：  
Node.js/TypeScript CLI 或 VS Code 扩展；OpenAI API；SQLite 存历史；npm 发布；可选 Supabase 做云同步。

**AI 用法**：  
分类、抽取、生成命令、检索文档。

**如果我来开发，最大难点**：  
安全。自动执行 AI 生成的命令可能删库、泄露密钥；跨平台 shell 差异大；上下文不足时 AI 会瞎猜。

**捷径**：  
只读诊断，不自动执行；只支持一个框架，比如 Next.js + Supabase；让用户手动确认每条命令；先做免费 CLI 收集反馈。

### 6）适合 OPC 初学者的机会
- **更小众版本**：Next.js 部署错误解释器；Supabase SQL 报错助手；Docker 命令生成器。
- **第一批访谈客户**：在 X、Discord、Indie Hackers 上公开 vibe coding 的开发者。
- **1 周验证实验**：做一个只解释 Next.js 构建错误的 CLI 原型，在 X 发 3 个真实案例，收集 20 个等待名单。

**证据不足说明**：Termi Protocol 收入太低，功能名称只能推断。它适合学习“微型开发者工具如何起步”，不适合作为高收入样本。

## 今日模式

**模式：新工具制造“迁移债务”。**

当 AI 建站、AI 编码、AI 音频工具大量普及，用户会产生新的“输出物”——网站、代码、音频、文档。这些输出物经常需要进入旧生态：WordPress、企业 CMS、播客平台、合规系统。

个人创业者可以不参与最卷的生成层，而是做迁移、转换、审核、发布、合规。WPConvert.ai 就是这个模式的样本：AI 建站越流行，迁移到 WordPress 的需求越多。

**第二个模式：低 MRR 微 SaaS 是学习样本，不是收入目标。**  
Termi Protocol $73/月、CogniGuide $700/月在 TrustMRR 上出售，说明小产品也有交易价值。对初学者，重点不是嘲笑收入小，而是研究它们为什么能收到第一笔钱、multiple 为什么不同。
